# 📊 Flipkart Mobile Sales Dashboard

A Power BI dashboard built to analyze Flipkart mobile sales data using interactive visualizations and business KPIs.

## Dashboard Preview

![Dashboard](Images/dashboard.png)

---

## Project Overview

This dashboard provides insights into mobile sales performance across different cities, brands, payment methods, and time periods. It enables users to explore trends and key business metrics through interactive filters.

---

## Key Metrics

- Total Sales Revenue
- Total Units Sold
- Total Transactions
- Average Selling Price

---

## Dashboard Features

- Sales by City
- Monthly Units Sold Trend
- Brand-wise Sales Analysis
- Mobile Model-wise Sales
- Customer Ratings
- Payment Method Distribution
- Sales by Day of Week
- Interactive Filters
